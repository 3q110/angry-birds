# 🐦 愤怒的小鸟 - Angry Birds

一个使用原生 Canvas + JavaScript 开发的经典「愤怒的小鸟」网页小游戏，无需任何第三方依赖。

## 🎮 在线试玩

👉 **[点击这里在线试玩](https://3q110.github.io/angry-birds/)**

## 📖 游戏规则

### 目标
用弹弓发射小鸟，消灭关卡中所有的小猪即可过关。

### 操作方式

| 操作 | 说明 |
|------|------|
| **瞄准** | 点击/触摸小鸟并向后拖拽 |
| **发射** | 松开鼠标/手指，小鸟沿反方向飞出 |
| **轨迹预览** | 拖拽时会显示虚线预测弹道 |

### 游戏元素

- 🐦 **小鸟** — 你的弹药，每关数量有限，合理使用；发射出去的小鸟落地后即快速消失
- 🐷 **小猪** — 需要消灭的目标，全部消灭即过关；失去方块支撑后自由落地即判死
- 🧊 **玻璃** — 最脆：一次满攻击碎（HP: 10）
- 🪵 **板材** — 中等：1.5 次满攻击碎（HP: 15）
- 🪨 **石头** — 最硬：2 次满攻击碎（HP: 20）

> 无直射角度时，小鸟沿抛物线从上方俯冲砸中结构会获得额外"砸落加成"，自由落体的破坏力更大。

### 计分规则

| 事件 | 得分 |
|------|------|
| 消灭一只小猪 | +100 分 |
| 摧毁一个方块 | +10 分 |

### 关卡

游戏共 **5 个关卡**，难度逐步递增：

1. **第 1 关** — 入门：1 只猪，板材结构
2. **第 2 关** — 进阶：2 只猪，玻璃/板材混合结构
3. **第 3 关** — 挑战：3 只猪，石/板材混合堡垒
4. **第 4 关** — 困难：4 只猪，双层复合结构
5. **第 5 关** — 终极：5 只猪，石头堡垒

### 功能按钮

| 按钮 | 说明 |
|------|------|
| 🔄 重新开始 | 重置当前关卡 |
| ⬅️ 上一关 | 返回上一关 |
| ➡️ 下一关 | 跳到下一关 |

## 🛠️ 技术栈

- **HTML5 Canvas** — 游戏渲染
- **原生 JavaScript** — 游戏逻辑（浏览器版由 `build-browser-bundle.js` 打包为单文件，支持直接双击打开；微信小游戏版使用 ES 模块）
- **物理引擎** — 自研轻量级 2D 物理系统（重力、碰撞检测、弹性碰撞）

## 🚀 本地运行

**方式一（推荐，最简单）：直接双击 `index.html`**

无需任何服务器/依赖，用浏览器（Chrome/Edge）直接打开 `index.html` 即可玩。

**方式二：本地服务器**

```bash
# 克隆仓库
git clone https://github.com/3q110/angry-birds.git

# 进入目录
cd angry-birds

# Windows：双击 start-server.bat（会自动打包并启动服务器）
# 其他平台：
python -m http.server 8080
# 或
npx serve .
```

然后在浏览器中打开对应地址即可。

> ⚠️ **打包说明**：浏览器版实际加载的是 `js/browser-bundle.js`（由 `node build-browser-bundle.js` 从 `js/` 各 ES 模块拼接生成，以便在 `file://` 下运行——浏览器协议禁止在本地文件中加载 ES module）。修改 `js/` 下任何模块后，请重新运行 `node build-browser-bundle.js`（`start-server.bat` 会自动执行这一步）。

## 📱 微信小游戏

同一套 `js/` 模块也用于微信小游戏（`game.js` → `js/main.js`，横屏）：

- 用开发者工具导入本目录即可运行（`project.config.json` 已配置）
- 音效使用 Web Audio API 合成，微信环境自动静默（无声音但玩法一致）
- 关卡按 900x600 设计，在小屏设备上右侧结构可能略靠边

## 📁 项目结构

浏览器版与微信小游戏版**共用 `js/` 模块**（单一代码源，行为一致）：

```
angry-birds-minigame/
├── index.html          # 浏览器版入口（仅 DOM/CSS，加载打包后的 browser-bundle.js）
├── build-browser-bundle.js  # 打包脚本：js/ 模块 -> js/browser-bundle.js（node build-browser-bundle.js）
├── game.js             # 微信小游戏入口
├── game.json           # 微信小游戏配置（横屏）
├── js/
│   ├── browser-bundle.js # 浏览器版打包产物（自动生成，请勿手改）
│   ├── main-browser.js # 浏览器版主程序（按钮、自适应缩放、音效）
│   ├── main.js         # 微信小游戏主程序（wx.createCanvas）
│   ├── physics.js      # 物理引擎（重力、摩擦、弹跳）
│   ├── collision.js    # 碰撞检测系统（鸟/方块/猪互撞 + 音效触发）
│   ├── sound.js        # 音效（Web Audio 合成，非浏览器环境自动静默）
│   ├── bird.js         # 小鸟类
│   ├── pig.js          # 小猪类
│   ├── block.js        # 方块类（玻璃/板材/石头）
│   ├── slingshot.js    # 弹弓渲染与弹道预测
│   ├── scenes.js       # 背景场景（天空、云、山丘）
│   ├── ui.js           # UI 渲染（顶栏、胜利/失败界面）
│   ├── input.js        # 输入管理（鼠标 + 触摸）
│   └── level.js        # 关卡数据（5 关）
└── start-server.bat    # Windows 一键启动脚本
```
